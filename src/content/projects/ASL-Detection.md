# The Picture

The idea was to have an interesting way for people using ASL to interact with others in their daily life. The prompt for this project was "AI in your everyday life." I thought about how Machine Learning could be the thing that helps someone using ASL to communicate. Although maybe not as robust as someone just learning ASL, I hope my system can provide a unique way for someone to talk with someone, reducing barriers to communication.

## The Progress

The repository as it stands right now has a word_writer.py that you can run locally on your machine to test the ML and write words using it in ASL alphabet. This also includes delete and space. Although, it needs to be better. There needs to be massive data to include all dialects and versions of ASL. Right now, only 3 datasets (including one make personally) are there. Suggestion is to maximize light on your hand, and angle the camera direct with your hand. Best of luck!
